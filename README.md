# ProjectPricely

Home improvement cost calculators: 10 services x 5 states (CA, TX, FL, NY, WA) plus national pages - 61 pages with interactive calculators and 2026 cost data.

**Live site: https://projectpricely.pages.dev**

This repo mirrors the deployed static site. Canonicals, sitemap and robots.txt all point at the pages.dev host (the projectpricely.com domain is not yet registered).

`fluxgen.py` / `upscale.py`: FLUX.1-schnell image pipeline via Cloudflare Workers AI (stock-image track, currently parked).
